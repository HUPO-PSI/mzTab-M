== Citing mzTab-M 2.0

When you use the mzTab-M 2.0 format in your work, please cite:

____
N. Hoffmann et al.
_mzTab-M: A Data Standard for Sharing Quantitative Results in Mass Spectrometry Metabolomics._
Analytical Chemistry 2019, 91, 3302–3310.
https://pubs.acs.org/doi/10.1021/acs.analchem.8b04310[DOI: 10.1021/acs.analchem.8b04310] | https://www.ncbi.nlm.nih.gov/pubmed/30688441[PubMed: 30688441]
____

== Citing jmzTab-m

When you use the jmzTab-m library or web validator in your work, please cite:

____
N. Hoffmann, J. Hartler, R. Ahrends.
_jmzTab-M: A Reference Parser, Writer, and Validator for the Proteomics Standards Initiative mzTab 2.0 Metabolomics Standard._
Analytical Chemistry 2019, 91, 12615–12618.
https://pubs.acs.org/doi/10.1021/acs.analchem.9b01987[DOI: 10.1021/acs.analchem.9b01987] | https://www.ncbi.nlm.nih.gov/pubmed/31525911[PubMed: 31525911]
____

The source code is available in the https://github.com/lifs-tools/jmzTab-m[jmzTab-m repository].

The repository's link:https://github.com/HUPO-PSI/mzTab-M/blob/main/CITATION.cff[CITATION.cff] file contains both references in machine-readable form; GitHub offers it as "Cite this repository" on the repository page.

If your work uses mzTab version 1.0 for proteomics, please cite:
